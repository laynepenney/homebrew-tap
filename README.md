# Homebrew Tap

Homebrew formulae for laynepenney packages.

## Installation

```bash
brew tap laynepenney/tap
```

## Available Formulae

### codi-repo

Multi-repository orchestration CLI for unified PR workflows.

```bash
brew install laynepenney/tap/codi-repo
```

Or after tapping:

```bash
brew install codi-repo
```

### Usage

```bash
# Full command
codi-repo sync

# Short alias
cr sync
```

See [codi-repo](https://github.com/laynepenney/codi-repo) for full documentation.
